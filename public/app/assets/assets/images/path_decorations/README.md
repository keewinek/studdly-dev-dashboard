# Learning path decorations

Every `.png` / `.webp` in this folder is scattered automatically over the
learning path (topic detail page) next to the subtopic nodes — no code
change needed. Files are used in alphabetical order.

Guidelines:
- Colorful, playful 3D objects on a **transparent** background.
- Square-ish, about 256×256 px (shown at ~54–70 px).
- No sloths — the sloth is Studdly's mascot.
- Only use images whose license allows use in the app (e.g. the Pixabay
  Content License) and note the source below.
